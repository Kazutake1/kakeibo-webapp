# 家計簿Webアプリ v2.0.3

Excel家計簿をベースにした iPhone / iPad / Mac 対応のレスポンシブPWAです。

## v2.0.3
- スマートフォンの概要画面上部に「今日の支出を入力」を追加
- 金額欄は `680+1250+320` のような計算式入力に対応
- スマートフォンでは月間予算と利用状況の各カテゴリーを折りたたみ表示
- 詳細入力から収入・固定費など従来の収支入力も利用可能


## v2.0.3
- 参考UIをもとに、白・淡いブルー基調のカード型UIへ刷新
- スマートフォンでは「今日の支出入力」を最優先表示
- 最近の入力をホームに追加
- 既存の予算・週間比較・グラフ機能は維持
