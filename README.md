# 家計簿Webアプリ v1.5.0

Excel家計簿の構成をベースにした、iPhone / iPad / Mac対応のレスポンシブPWAです。

## 主な機能
- 月ごとの収入、社会保険・税金、貯蓄、自己投資、固定費、特別費、変動費
- 予算と実績の比較
- 変動費の日別入力表
- 週間推移グラフ
- 支出構成・変動費構成のドーナツグラフ
- 収支の追加・編集
- 月移動
- JSONバックアップ / 復元
- オフライン利用
- iPhone / iPad の「ホーム画面に追加」に対応

## 現在のデータ保存方式
データはブラウザの localStorage に保存します。端末ごとに独立して保存されます。

### 端末間の自動同期について
同じデータを iPhone / iPad / Mac 間で自動同期するには、次の版でクラウドDB（Supabase / Firebase など）を接続する必要があります。

## 公開方法
GitHub Pages / Cloudflare Pages / Netlify などのHTTPSホスティングに `index.html`, `manifest.json`, `sw.js`, アイコン2枚を置けば利用できます。
