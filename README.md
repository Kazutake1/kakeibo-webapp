# 家計簿Webアプリ v2.3.6 Stable

Excel家計簿をベースにした iPhone / iPad / Mac 対応のレスポンシブPWAです。

## v2.3.6 Stable
- スマホ版「日別」の日付ピッカー変更をその場で反映
- 前日・翌日、左右スワイプ、日付ピッカーの更新処理を共通化
- iPhone Safari向けに日付入力の `input` / `change` の両イベントへ対応
- 選択日と月表示の状態同期を整理し、日付変更時の全体再描画依存を解消

## v2.3.5 Stable
- 正式採用済みの家計簿アイコンの意匠を維持し、黒ベースの配色へ変更
- `icon-192.png` と `icon-512.png` を更新
- ヘッダー左のマークをPWAアイコン画像へ統一
- manifest / theme color / Service Workerキャッシュを更新
