# 家計簿Webアプリ v2.4.4 Stable

Excel家計簿をベースにした iPhone / iPad / Mac 対応のレスポンシブPWAです。

## v2.4.4 Stable
- スマホ版とPC/Web版の太陽マークを同一デザインへ統一
- 端末ごとのUnicodeフォント差を避けるため、太陽マークを固定SVGへ変更
- 太陽アイコンのサイズを20pxに固定し、スマホでもWeb版と同じ見た目になるよう調整

## v2.4.3 Stable
- ライト / ダーク切替の月・太陽アイコンの表示領域を統一
- 小さく見えていた太陽アイコンを視覚的に月と同等サイズへ調整
- アイコン切替時もボタン内の位置がずれないよう中央配置を固定

## v2.4.2 Stable
- 日別ページで金額が入っている項目をタップすると、その日の個別入力履歴を表示
- 履歴ごとに「編集」「削除」を追加
- 編集では金額（計算式対応）・店名/内容・メモを修正可能
- 削除前に確認ダイアログを表示し、誤削除を防止
- 保存失敗時は編集・削除・追加をロールバックして画面と保存データの不一致を防止
- Mac / iPad の日別表でも、入力済みセルをクリックすると個別履歴を開ける

## v2.4.1 Stable
- Mac / iPad版の日別一覧表で、金額をセル内の縦横中央に配置
- 日別セルと合計セルの中央揃えを統一
- ライト / ダークモードの両方で配置が崩れないようCSSを補強

## v2.4.0 Stable
- スマホ版「日別」ページ最上部に月間収支カレンダーを追加
- 各日に収入を青色、支出を赤色で表示
- 日付をタップすると既存の日別入力表示がその日に切り替わる
- 日曜日・祝日は赤、土曜日は青で表示
- 既存の日別入力UIはカレンダーの下にそのまま維持
- 日別ページ表示中は上部の前月/翌月操作と選択日を同期
